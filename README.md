### SAGE — LLM Function Calling Benchmark

**Master's Thesis | Python · LLMs · Evaluation**

A reproducible evaluation pipeline comparing specialized small language models and generalist LLMs on single-turn function calling tasks.

Includes a synthetic benchmark of 210 cases, automated validation and evaluation, multiple model backends, and an analysis of 23 model/prompt configurations.
